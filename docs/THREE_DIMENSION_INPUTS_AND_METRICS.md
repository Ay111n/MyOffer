# 三维比较：收集项与报告指标

当前目录共 59 个字段，其中 57 项直接显示，年终奖月数与单位公积金比例根据可见输入联动生成。比较 2–3 份毕业后全职 Offer。`*` 为生成综合排名所需的七项；其余均可跳过。用户填写城市选择、数值或固定选项，不收公司名、岗位名、股票或期权，也不收存款、贷款等个人财务数据。

## 收集项

| 维度 | 收集项 |
| --- | --- |
| 经济回报（24） | 工作城市*、税前月薪*、固定薪数*；年终奖方式、年终奖金额、年终奖月数（按方式填写）；签字及安家费、搬迁安置补助、政府人才补贴、固定月补贴、餐食、住宿；社保缴纳类型、社保基数、公积金缴纳类型、个人公积金比例、单位公积金比例（由前端联动填写）、公积金基数、专项附加扣除类别；试用期月数、试用期工资比例、约定年度调薪比例、补充医疗年度价值、年度加班值班补偿。 |
| 职业成长（16） | 业务范围*、新人承担层级*；带教机制、反馈频率；岗位内容匹配度、自主决策程度、问题复杂度、技能通用性；年度培训天数、年度培训预算、内部轮岗转岗、成果展示许可、AI 工具使用、接触用户或业务结果、与个人目标的契合度、项目阶段。 |
| 工作体验（19） | 周工作时长*、每周工作天数*；单程通勤、每月出差天数；旺季每周工时、年度旺季周数、每月周末加班天数、值班频率、下班后响应频率；每周远程天数、弹性工作时间、额外带薪假期；会议与临时任务、主管支持、团队表达氛围、办公环境舒适度、绩效淘汰压力、工作认同感、个人项目限制。 |

未填写问卷时，默认权重为经济回报 34%、职业成长 33%、工作体验 33%，并按考虑买房计算。完成问卷后，可在结果确认处直接调整三个数字和选择购房意向。这些是用户的比较偏好，不属于某一份 Offer。

## 报告呈现

| 层次 | 指标与用途 |
| --- | --- |
| 总览 | 排名、综合分、三维分及总分卡片下方的偏好权重声明。七项必需信息未全时展示分项与缺口，不给总排名。显示同分并列。 |
| 经济回报 | 常规年度收入、入职阶段收入、试用期、购买力、福利、买房压力各有独立子分。入职阶段三项用名义金额直接相加，不并入常规年度税后现金。买房压力仅在考虑买房时入分。 |
| 职业成长 | 业务机会、承担与自主为基础子分；技能积累、培养支持、后续选择空间在相应信息参与本轮评分时出现。项目阶段保留在填写页，不按“阶段越新越好”强行评分。 |
| 工作体验 | 时间占用与休息安排为基础子分；工作边界、日常环境在有共同可比信息或明确增益时出现。时间占用列每周小时及已入分的旺季、通勤折算；休息安排列每周休息天数与额外假期；工作边界列已入分的出差或周末加班年度频率。有效税后时薪不入分，因此不在报告主体展示。 |
| 明细 | 二级结果按同一行横向并列；每个二级分类和结果字段后的说明标识解释其计算口径。完整原始输入在填写页查看和修改。税后与五险一金弹窗显示逐月个税、个人和单位缴纳。可打印或保存 PDF。 |

## 入分口径

- 现金、餐宿、补充医疗、培训、带教、远程、额外假期等可理解为「没有就是零」的增益项：有一份填写就形成差异并入分，其他空白按零或最低档处理；用户补填后重新计算。
- 通勤、出差、旺季工时、周末加班等负担项，以及没有自然零值的同题评价：只有所有 Offer 都填写该项后才影响排名。单方已知值仍在明细中可见。
- 年终奖按现有个税规则估算。入职阶段收入以名义金额合计并单独评分；试用期少拿金额以名义金额单独评分，两者都不并入常规年度现金。约定调薪只影响常规年度收入子分，年度加班补偿按固定现金的有效到手比例估算。
- 成长与体验的二级分类按规则权重合成；只有基础项时，在有效类别之间重新归一。未形成共同对比基础的扩展评价不参与本轮分数，同一字段不在两个子分中重复计分。额外假期只进入休息安排，不再从普通周工时扣除。
