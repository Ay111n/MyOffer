# 示例 Offer 的取值依据

示例 A/B/C 是供体验与调试使用的合成 Offer，分别模拟北京 Java 开发、成都后端开发和上海软件开发岗位。三份都有可取之处，展示不同城市、收入和工作条件之间的取舍。它们不对应下列招聘单位实际发出的录用通知。

公开职位给的是招聘薪资区间，不是个人最终录用金额。固定薪数、奖金、补贴、五险一金、通勤和主观评价等字段用于构造有辨识度的完整示例；除招聘页面明确写出的条件外，均为演示假设。不要据此推断上述公司的真实待遇或工作体验。

## 2026-10 重设计：维度互搏的教学示例

非薪资字段按「难以区分、但仍有差距」的目标用评分引擎迭代锁定，供「先看一份示例报告」一键演示除 AI 解读外的全部功能：

- **A 星澜科技（北京）**：经济与成长双强（4 个月年终 + 签字费、own_module、直接接触用户），强度高（50h、通勤 50、每周下班响应、周末加班）——默认权重下以约 1.2–1.5 分微弱领先，敏感性 fragile；
- **B 蓉创信息（成都）**：体验最舒适（44h、无值班、弹性、远程），成长一般，按最低基数缴费（触发合规告警与评分参考现金双轨展示）；
- **C 浦海数据（上海）**：成长第一（core 业务、own_module、调薪 8%），体验居中。
- 旺季工时只在 B/C 填写（A 留空）：触发「部分可比字段」提示与下一步建议——补填 A 后其分数下降、领先易主，正好演示「补齐信息会改变结论」。
- 数值验收口径（改动示例前后请用引擎回归）：默认权重（考虑买房）A 领先 C ≈1.2 分、领先 B ≈1.5 分，敏感性 margin ≈5 个百分点；等权（不考虑买房）三份分差 ≈2.7 分；B 的追平月薪 ≈¥15,600（+¥4,600）、C ≈¥21,200（+¥4,200）。
