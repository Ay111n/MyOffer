# 示例 Offer 的取值依据

示例 A/B/C 是供体验与调试使用的合成 Offer，分别模拟北京 Java 开发、成都后端开发和上海软件开发岗位。三份都有可取之处，展示不同城市、收入和工作条件之间的取舍。它们不对应下列招聘单位实际发出的录用通知。

| 示例 | 税前月薪 | 公开校招信息 |
| --- | ---: | --- |
| A · 北京 | ¥15,000 | [中南大学就业信息网，北京 Java 岗 ¥12,500–15,000/月](https://career.csu.edu.cn/campus/view/id/581721)，2025-06-25 发布，接受计算机相关本科专业。 |
| B · 成都 | ¥11,000 | [四川大学就业指导中心，成都后端开发岗 ¥10,000–25,000/月](https://jy.scu.edu.cn/index/index/employjobdetail.html?data=MDAwMDAwMDAwMJG6n3_Ed6imi4qQtLh4iN-Kuba-s4bddricp9CWi5qikaeWacSdqLqGfaK2w4iil5C4zNbGiL-E)，2025-08-27 发布，最低学历本科。 |
| C · 上海 | ¥17,000 | [中南大学就业信息网，上海软件工程师岗 ¥15,000–17,500/月](https://career.csu.edu.cn/teachin/view/id/113254)，2025-09-18 宣讲，接受软件工程、计算机等本科专业。 |

公开职位给的是招聘薪资区间，不是个人最终录用金额。固定薪数、奖金、补贴、五险一金、通勤和主观评价等字段用于构造有辨识度的完整示例；除招聘页面明确写出的条件外，均为演示假设。不要据此推断上述公司的真实待遇或工作体验。
